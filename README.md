# CSI Event Companion

A simple mobile-first student project for the CSI AITR Student Chapter.

## Open it

Open `index.html` in a modern browser. Keep `styles.css`, `script.js`, and the `assets` folder alongside it. No install, server, account, or internet connection is required.

## What works

Browse eight sample events, search and filter, view details and schedules, register, bookmark events, and edit a demo profile. Registrations, bookmarks, and profile edits are saved in your browser's localStorage. They are only available in that browser and are not sent to the chapter.

## Files

- `index.html` — page layout and registration form
- `styles.css` — mobile-first styling and desktop layouts
- `script.js` — sample event information and interactive behavior
- `assets/csi-logo.png` and `assets/aitr-logo.png` — supplied chapter and institute marks
